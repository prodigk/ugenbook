## 📚 서평 아카이브 사이트 기획

### 1. 메인 페이지 — 서재 뷰

- **책 표지 그리드**: frontmatter의 `bookcover` 이미지를 활용한 깔끔한 카드 레이아웃
- 다크모드, 라이트모드 기능 추가
- **필터/검색**: 태그, 저자, 작성상태(작성중/완료) 기준 필터링
- **정렬**: 최신순, 저자순, 제목순

### 2. 도서 상세 페이지

- 책 표지 + 메타정보(저자, 태그, 상태) 헤더
- 메타정보 카테고리 추가 (경제, 인문 사회 과학, 커리어, 철학 등)
- 옵시디언 마크다운 본문 렌더링 (하이라이트, 인용, 리스트 등 지원)
- 챕터별 접기/펼치기 (아코디언)

### 3. 관리자 기능 (md 파일 업로드)

- **드래그앤드롭 업로드**: 여러 md 파일을 한번에 업로드
- frontmatter 자동 파싱하여 도서 정보(제목, 저자, 표지, 태그, 상태) 추출
- 기존 도서 업데이트(같은 파일명이면 덮어쓰기)
- 업로드된 도서 목록 관리 (삭제, 상태 변경)
- 카테고리 관리

### 4. 블로그 콘텐츠 변환 & 발행

- **네이버 블로그용 변환**: md → HTML 변환, 네이버 블로그 API(Open API)로 자동 발행 버튼
- **브런치용 변환**: 브런치는 공식 API가 없으므로, 브런치 에디터에 최적화된 HTML로 변환 후 **클립보드 복사** 방식 제공
- 각 도서 상세 페이지에 "네이버 블로그 발행" / "브런치 복사" 버튼 배치
- 발행 이력 관리 (어디에 발행했는지 표시)

### 5. 백엔드 (Lovable Cloud / Supabase)

- **도서 테이블**: 제목, 저자, 표지URL, 태그, 상태, md원문, 생성일, 수정일
- **발행이력 테이블**: 도서ID, 플랫폼(네이버/브런치), 발행일, 발행URL
- **네이버 블로그 API 연동**: Edge Function에서 네이버 Open API 호출
- **인증**: 관리자 로그인 (업로드/발행은 로그인 필요, 아카이브 열람은 공개)

### 6. 디자인 — 미니멀 서재

- 화이트 배경, 따뜻한 세리프 폰트 포인트
- 책 표지 중심의 카드 UI, 여백 여유
- 모바일 반응형
