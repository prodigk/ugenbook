# BookReview Sync

옵시디언에 정리해둔 첨부파일 같은 각각의 도서정리 .md 파일들로 구성된 서평 정리 아카이브 사이트를 만들고 싶어. 옵시디언에 작성된 100여개의 md파일이 있고 각 도서의 정보들이 담겨있어. 이파일들을 활용해서 네이버 블로그, 브런치 서비스에 맞는 내용이 생성되고 자동으로 업로드되는 기능을 포함해서 기획해줘. 각 도서 서평은 지속적으로 옵시디언에 생성하고 업데이트할 예정이야.
